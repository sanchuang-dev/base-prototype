# 社区家庭健康小程序｜产品结论 V0.3

> 本文收敛 2026-09-19 本轮产品访谈与原型修订结论，作为当前首页与社区/广电能力设计契约。V0.3 在 V0.2 基础上继续收敛，不推翻五个一级 Tab。

## 1. 当前产品定义

产品面向街道辖区居民，重点覆盖中老年用户，但不限定为“老人 App”。

核心组成：

**社区生活 + 家庭健康 + 广电服务 + 积分权益 + 本地生活**

产品首先应让居民感受到：

- 社区今天有什么事
- 刚才小喇叭说了什么
- 有什么活动、福利或服务
- 广电手机卡、宽带、电视业务在哪里办
- 有多少积分、能换什么
- 健康服务如何进入家庭

不是政府综合管理系统，也不是单纯健康商城。

## 2. 首页 V0.3 结构

首页调整为更符合国内社区小程序心智的传统结构：

1. Banner
2. 常用服务
3. 广电服务强露出
4. 固定金刚区
5. 可配置服务入口
6. 社区消息 / 社区广播
7. 今日社区活动
8. 我的积分
9. 今日健康
10. 惠生活

Banner 允许承载：

- 重点社区活动
- 广电服务日
- 节庆主题
- 党群活动
- 健康服务活动
- 季节性通知

Banner 不作为纯装饰，点击应进入具体活动或服务。

## 3. 广电服务必须显眼

“广电服务”不得只作为一个普通金刚区，也不得只藏在“我的”。

首页使用独立重点卡片，直接露出四项居民能理解的业务：

- **手机卡**
- **宽带**
- **电视**
- **上门服务**

首页不用“192 通信”“家庭网络业务”等行业黑话。

进入广电服务页后，再进一步承载：

- 手机卡选号 / 套餐 / 新办 / 咨询
- 宽带新装 / 提速 / 套餐 / 故障服务
- 电视套餐 / 会员 / 机顶盒服务
- 装维上门 / 教学 / 维修 / 售后
- 家庭融合套餐
- 我的广电权益
- 上门服务记录

当前真实接口未确认的能力统一标记为“筹备接入 / 演示”。

## 4. 固定金刚区

广电服务独立强露出后，首页保留 4 个固定核心入口：

- 社区广播
- 健康服务
- 党群文化
- 社区活动

这四项体现平台的长期产品骨架，不随单个项目轻易删除。

## 5. 其它入口必须可配置

除固定金刚区外，其他首页服务入口不写死。

由街道 / 社区 / 项目运营资源决定，可按项目配置 6–8 个高频入口。

示例：

- 学习服务
  - 老人大学
  - 儿童兴趣班
- 办事指引
- 社区食堂
- 街坊消息
- 助老服务
- 志愿服务
- 便民维修
- 邻里互助
- 集体福利
- 更多服务

“太公分猪肉”这类现实社区信息，不需要被产品语言净化掉，可作为“街坊消息 / 集体福利”下的具体内容。

产品要像社区真实生活，而不是抽象“智慧治理”。

## 6. 社区小喇叭 / 社区广播

社区广播是广电体系非常有辨识度的能力之一。

典型内容包括：

- 暴雨、台风、停水停电等公共提醒
- 公共卫生 / 安全 / 反诈信息
- 社区治理与办事通知
- 党群文化活动
- 社区文艺活动
- 便民服务通知

产品链路：

**社区广播负责第一触达 → 小程序负责重听、文字稿、详情、报名、提醒和后续服务。**

例如：

“今晚 19:00 篮球场有文艺演出”

进入小程序后承接：

- 文字详情
- 时间地点
- 节目内容
- 报名
- 提醒
- 到场签到
- 积分

每条广播 / 社区消息应显示发布来源，例如：

- 街道
- 社区居委会
- 党群服务中心
- 相关公共部门
- 广电社区服务

### 广播边界

应急广播和公共广播保持公共服务属性。

不得把公共广播直接设计为商品广告机。

商业转化应发生在用户主动进入小程序之后，并明确区分公共信息、健康科普和商业推荐。

## 7. 社区生活内容

老人高频社区生活不需要过度创新，真实内容本身就是产品价值：

- 下象棋
- 写书法
- 太极
- 广场舞
- 合唱
- 粤曲
- 老人大学
- 兴趣班
- 社区食堂
- 文艺演出
- 集体福利
- 便民通知

“党群文化中心”继续作为核心固定场景。

## 8. 健康与积分保持原有原则

健康是长期价值线，不抢首页第一注意力。

继续保留：

- 社区助手
- 健康讲堂
- 家庭健康设备
- 魔镜
- 健康档案
- AI 辅助理解

积分不是一级产品，而是贯穿活动、内容、服务和惠生活的权益机制。

居民只需要理解：

**我有多少积分 → 今天还能赚多少 → 能换什么。**

## 9. 当前首页视觉原则

V0.3 视觉强调：

- 第一屏更像真实小程序，不再像项目验收系统
- Banner 允许“俗套”，因为低学习成本比形式创新重要
- 广电服务视觉权重高于普通入口
- 手机卡 / 宽带必须直接可见
- 金刚区保持大字号和足够触控面积
- 可配置服务入口控制在 6–8 个
- 社区信息用生活化文案
- 不使用大量抽象科技插画
- 适老辅助文字不低于 14px

## 10. 当前五个一级 Tab

保持不变：

**首页 / 社区 / 健康 / 惠生活 / 我的**

V0.3 不新增一级 Tab。

## 11. 本轮一句话结论

首页不再证明“平台有多少能力”，而是按照居民习惯先给出：

**Banner → 广电业务 → 常用服务 → 可配置社区服务 → 社区消息。**

其中广电手机卡、宽带、电视和上门服务成为显性业务入口；社区广播继续承担广电差异化触达能力；其它社区服务保持可配置，允许产品真正适配不同街道的现实资源。
