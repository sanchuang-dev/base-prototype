# 社区本地生活｜客户演示原型

本分支是「社区家庭健康 + 本地生活 + 广电服务」概念原型的独立长期源码分支。其产品约束以 [PRD V0.3](docs/PRD-V0.3.md) 为准。

- 项目类型：对外静态演示，非真实业务系统。
- 发布目标：由 `base-prototype/main` 统一构建，路径为 `/base-prototype/local-life/`。
- 原有历史资源：`release/`、`source/`、`patches/`。现行发布脚本从本分支的 `release/v0.3.1/` 重建演示，并沿用既有路由兼容修复。
- 仓库级规约以 [main/AGENTS.md](https://github.com/sanchuang-dev/base-prototype/blob/main/AGENTS.md) 为准，本分支 `AGENTS.md` 仅补充项目级要求。

独立分支不与岭南等其他客户原型互相合并。原仓库的根目录已规划为项目入口大厅。
