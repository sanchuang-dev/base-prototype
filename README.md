# 岭南红艾 · 客户演示原型

本分支 `feat/lingnan-red-mugwort-prototype` 是 **独立于 `main` 所载社区家庭健康服务平台** 的岭南红艾演示项目，不向 `main` 合并，亦不接管其 GitHub Pages。

## 使用

直接打开 `index.html`，也可用任意静态服务器托管。无须构建、登录、API、密钥或数据库。

- 七个演示页面：品牌首页 / 红艾文化 / 礼遇甄选 / 企业定制 / 品牌共建 / 我的红艾（用户中心） / 艾礼试用所（赞助试样）。
- 导览、两种礼赠产品线、心愿清单、收藏、定制报价估算、预案文字下载、模拟验真、用户中心及赞助试样活动。
- **艾礼试用所**仅为第三方广告试样的 UI 演示：活动明示广告赞助、样品 ¥0、由用户承担独立展示的**示意运费**。没有实际广告主、申请记录、收货地址收集、扣费或发货；「我的试用」为空状态。底部导航展示试用所，文化页保留首页入口。
- 适配手机和电脑；电脑端为带演示导览的展示台。
- 原型自带说明：商家、合作、公益、订单、产品功效、溯源与数字均为演示样例；**不得作为实际商用证明**。

## 视觉来源

根据用户上传的 Stitch 五屏导出（首页合作看板、文化科普、品牌首页、礼盒商城、企业定制）与 `lingnan_red_mugwort_botanical_heritage/DESIGN.md` 改编。承袭深草木绿、朱砂红、宣纸白、新中式宋体层级。页面使用的 9 张 Stitch 导出图片已保存在本分支的 `assets/images/`（WebP），并在 `assets/images/sources.json` 记录原始来源与哈希。HTML 采用相对路径，国内访问无需连接 Google 图片服务。字体使用系统字体后备栈，不加载 Google Fonts。图片仅用于客户演示，正式商用前仍须核实素材使用权。

## 开发约定

- 这是可体验的静态原型：不写真实后台，也不伪造真实支付、订单或验真结果。用户中心通过浏览器 `localStorage` 保存**演示昵称、是否体验会员身份、城市偏好、收藏及礼单**；无真实注册、短信验证、密码、手机号、详细地址和云端同步。请勿输入真实个人资料。演示设置可清空本地数据。
- 所有功能新增都只维护本分支。保留 `main` 的现有社区产品及 Pages 发布流程，避免两条产品线交叉。
- 原型产品源码只在本分支；仓库 `main` 统一管理 Pages 发布。此分支不与社区项目合并，发布只读取明确登记的静态文件。
- `main/demos.json` 是分支到演示子路径的唯一发布映射；对外发布由 `main/.github/workflows/pages.yml` 统一完成。当前可在主分支 Actions 中手动运行发布工作流来同步本分支的改动。
